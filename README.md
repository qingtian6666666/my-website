# Bob Song - Personal Space

A personal website built with Vue 3 + Vite, featuring a dark theme with glassmorphism design, particle animations, and interactive UI.

## Features

- Particle background with mouse interaction and shooting stars
- Typewriter effect hero section
- Animated tech stack progress bars
- Music player with audio visualizer
- Development notes with local storage
- Smooth page transitions and scroll reveal animations
- Responsive design for all devices

## Tech Stack

- Vue 3 (Composition API)
- Vue Router 4
- Vite 5

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
